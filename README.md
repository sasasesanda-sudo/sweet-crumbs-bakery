# Sweet Crumbs Bakery - WEDE5020 POE

Sweet Crumbs Bakery is a small bakery based in Soweto, Johannesburg.
This website was created for WEDE5020 Web Development POE Part 1, 2 and 3.

## Features
- Homepage, About, Services and Enquiry pages
- Responsive navigation that works on mobile
- JavaScript Order Now pop-up alert
- Functional enquiry form with validation
- SEO: Title, meta description, keywords and alt text
- Google Maps embedded showing Soweto location

## Live Website
https://sasasesanda-sudo.github.io/sweet-crumbs-bakery/

## Technologies
HTML, CSS, JavaScript
